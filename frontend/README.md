# Task Management - React

## Description

Task manager with React -Vite.

## Task stack

This project is build using:

- React + TypeScript
- Vite
- TanStack Query
- Reach hook form
- Axios
- Tailwind
- React-router-dom

## Feature

- Task list with pagination
- Create task
- Update task status
- Delete task
- Update task

## Project setup

1. Firstly, make sure you are in the `/frontend` directory.
2. Run the node modules installation

```bash
$ pnpm install
```

`Note`:

a. If you are using other package manager, you can firstly delete the:

```bash
pnpm-locl.yaml
pnpm-workspace.ymal
```

b. Then you can savely install the node modules using your node package manager

## Compile and run the project

```bash
# development
$ pnpm run start
```

`Note`: If you are using other package manager, you can change the pnpm with your package manager (e.g npm or yarn)
